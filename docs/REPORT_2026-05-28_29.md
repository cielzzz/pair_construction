## 1. 项目背景

### 1.1 源数据本质

源数据由数据组从网上爬取，经过：视频转音频 → 去 BGM → 降噪 → 响度规整 → 说话人分类 → 双 ASR 交叉验证。**非录音棚高质量音库**，所有下游指标 (DNSMOS / speaker_sim / WER) 有先天上限——这是后续所有阈值讨论的前提。

### 1.2 完整管线

```
[爬取 jsonl] (数据组)
   │
   ▼
vcdata_construction
  - MOSS-TTS 16 候选 voice clone（用同 speaker 别条作 prompt）
  - argmax(speaker_similarity) 选 ref_audio
  - 产出：original_audio, ref_audio, speaker_similarity
   │
   ▼
vc_edit (stepfun-editx)
  - 用 ref_audio 作 input，按 edit_tag 改造（zh 收敛到 style_radio / en style_chat）
  - 产出：edited_audio（文本与 ref_text 一致）
   │
   ▼
pair_construction
  - 04 emotion_eval：emotion2vec_plus_large + SenseVoiceSmall + DNSMOS_v4
  - 03 join（按音频路径匹配，已修 idx bug）
  - 05~10 构造 9 类 pair
  - 11_add_speaker_sim（CAM++）+ 11b_add_wavlm_sim（WavLM-L SeedTTSEval, 主指标）
```

### 5.4 优先级 4：caption / instruction 生成（重要修正）

PM 原话：「我们后面批量进行 caption 标注总能标出来的」

**澄清两个误区**：

1. **maoer 的 qwen3-omni caption 是 descriptive，不是 imperative**
   - 现状：`"summary": "A young woman's frustrated and assertive voice..."`（描述音频是什么样）
   - 训练需要：`"instruction": "Please read the following text in a calm tone"`（告诉模型要做什么）
   - 二者风格差异大，不能直接套用

2. **maoer caption 标的是 maoer 原音频，不是我们 pipeline 产出的 (ref / edited)**
   - 我们 pipeline 里 reference = edited_audio（editx 改造产物），target = ref_audio（MOSS-TTS clone）
   - maoer caption 跟我们的 reference / target 没有直接对应关系
   - 只能作为 source_audio 元数据辅助筛选（按 emotion / gender 过滤源数据），**不能直接当 instruction**

**正确的做法**：
1. **自己接 caption 模型**给我们 pipeline 产出的 (ref_audio, edited_audio, original_audio) 三段音频分别标注
2. **加 caption → instruction 转换**：用 LLM (Qwen3 / Claude) 把 descriptive caption 改写成 imperative 风格的指令，作为训练 instruction
3. **maoer caption 复用价值**：仅作为 source_audio 筛选辅助（按 maoer.emotion="happy" 找高表现源），加快规模化采样


#### caption → instruction 转换示例（5 个对照）

| 场景 | descriptive caption（maoer 自带）| imperative instruction（训练用）|
|------|--------------------------------|-----------------------------|
| 中性朗读 | 「一位中年男性平静地朗读文章，语气稳定」 | 「请用平静、不带情绪起伏的语气朗读以下文字」 |
| 愤怒对话 | 「一位年轻女性愤怒地与对方争执，语速快、字字铿锵」 | 「请用愤怒、急促的语气说出这段话」 |
| 喜悦分享 | 「一位男孩兴奋地分享好消息，声音明亮上扬」 | 「请用开心、雀跃的语气朗读，让人感到喜悦」 |
| 悲伤独白 | 「一位老人低沉地讲述往事，声音颤抖」 | 「请用悲伤、低沉的语气念这段文字」 |
| 紧张陈述 | 「一位女性紧张焦虑地解释情况，呼吸急促」 | 「请用紧张、犹豫的语气表达，仿佛在着急解释」 |

**B 类（中性 → 高表现）的 instruction 需要变体**：描述「**从 reference 到 target 的变化**」更精确：

| reference (caption) | target (caption) | 训练用 instruction（transformation 风格） |
|---------------------|------------------|-------------------------------------|
| 一位女性平静叙述 | 一位女性愤怒控诉 | 「保持音色，把语气从平静变成愤怒」 |
| 中年男性中性朗读 | 中年男性悲伤独白 | 「用同一个声音，把情绪从平静加强到悲伤」 |
| 年轻男性淡淡说话 | 年轻男性急切呼喊 | 「保持声音特征，把情绪强度从平静拉高到紧张」 |

**两条路线选择**：

| 方案 | 优点 | 缺点 |
|------|------|------|
| A. **Absolute 风格**（只描述 target）| 简单，instruction 模板可直接套用 | 忽略 reference，模型可能学不会"保留音色"|
| B. **Transformation 风格**（描述变化）| 更贴合 voice/style conversion 任务的本质 | 需要 ref + tgt 双 caption + LLM 改写 |

建议训练数据**两种风格各占 50%**，让模型同时学会两种 instruction 模式。
